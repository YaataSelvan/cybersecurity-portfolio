# Cybersecurity Portfolio

Personal cybersecurity portfolio built with Astro to showcase my experience, projects, technical skills, education, certifications, and contact information.

## Tech Stack
- Astro
- HTML
- CSS
- JavaScript
- Git/GitHub

## Features

- Responsive portfolio layout
- Experience and project tabs
- Skills grid
- Education and certifications sections
- Resume PDF
- GitHub, LinkedIn, email contact link

## 🧞 Commands

All commands are run from the root of the project, from a terminal:

| Command                   | Action                                           |
| :------------------------ | :----------------------------------------------- |
| `npm install`             | Installs dependencies                            |
| `npm run dev`             | Starts local dev server at `localhost:4321`      |
| `npm run build`           | Build your production site to `./dist/`          |
| `npm run preview`         | Preview your build locally, before deploying     |
| `npm run astro ...`       | Run CLI commands like `astro add`, `astro check` |
| `npm run astro -- --help` | Get help using the Astro CLI                     |
